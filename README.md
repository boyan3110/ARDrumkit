# ARDrumkit

**Version:** 1.0

## Introduction
This README provides instructions for downloading, installing, and running the Android application provided as an `.apk` file.

## Installation Instructions

### Step 1: Download the `.apk` File
- Download the `.apk` file from the [Git Repository](https://gitlab.com/a-group7613531/ardrumkit).

### Step 2: Install the `.apk`
1. **Enable Unknown Sources:**
   - On your Android device, go to `Settings > Security`.
   - Enable the option to install apps from `Unknown Sources`.

2. **Install the Application:**
   - Locate the downloaded `.apk` file in your device’s `Downloads` folder.
   - Tap on the `.apk` file to begin the installation process.
   - Follow the on-screen instructions to complete the installation.

### Step 3: Grant Camera Permission
- Upon launching the app for the first time, it will request permission to access the camera.
- **Ensure** that you grant this permission, as it is necessary for the app to function correctly.

## Troubleshooting

- **Issue:** Installation blocked.
  - **Solution:** Ensure that `Unknown Sources` is enabled in your device settings.

- **Issue:** Black screen in game.
  - **Solution:** Check that the app has camera permissions. If not, grant the permission.
